# 趋势结构跟踪器

## 理论来源

0xToni (@0xtonixie)《散户生存法则》第一期+第二期（2026-07-19/20）。
核心一句话：**趋势 = 高低点结构，不是均线方向。均线只是确认工具。**

## 0xToni 原始框架（三问法）

1. **有没有突破前高？** → 高点序列 HH or LH
2. **有没有跌破前低？** → 低点序列 HL or LL
3. **20日均线有没有转向？** → 确认/否认

| 组合 | 判定 |
|---|---|
| HH + HL + 20MA↑ | 上涨趋势确认 |
| LH + LL + 20MA↓ | 下跌趋势确认 |
| HH + HL + 20MA↓ | 结构转多，均线未确认（轻仓试探） |
| LH + LL + 20MA↑ | 结构转空，均线未确认（减仓观望） |
| 其他 | 无明确趋势（震荡/收敛/扩散） |

## ⚠️ 回测打脸结论（A 股 ETF, 2025-07 ~ 2026-07）

在科创50ETF/创业板ETF/通信ETF上验证：
- **"上涨趋势确认"信号买入，20日后平均亏损 -5% ~ -23%，胜率 0~40%**
- **"无明确趋势"（震荡期）反而收益最好，+2% ~ +6%，胜率 57~77%**
- 原因：A 股震荡市 > 趋势市；日线 HH+HL 经常是大级别下跌中的反弹陷阱

**结论：纯 0xToni 框架在 A 股不能直接用，必须叠加以下增强。**

## 缠论增强（必须叠加）

### 增强1：级别过滤
- 日线结构 HH+HL ≠ 可以买。先看**周线**结构：
  - 周线也是 HH+HL → 共振，信号有效
  - 周线是 LH+LL → 日线反弹是大级别下跌的中继，**不追**
- 实操：用 `swing_points(weekly_df, L=2, R=2)` 做周线结构

### 增强2：背驰检查（力竭过滤）
- 日线 HH+HL 但 MACD 面积递减 → 趋势力竭，不追
- 用缠论 v5t 的 `_detect_bei_chi` 或 MACD 面积对比
- 没有背驰的趋势确认才是真趋势

### 增强3：中枢区间替代 20MA
- 0xToni 用 20MA 作为"回调支撑带"，太粗糙
- 缠论用**最近中枢区间 [ZD, ZG]** 作为回调合理范围
- 回调进中枢 → 正常；回调破中枢下沿 → 趋势可能破了

### 增强4：三类买卖点
- 0xToni 只有"突破前高"一种入场（≈ 缠论一买/突破确认）
- 缠论三买（回调不进中枢）= 更安全的入场点
- 缠论二买（回调后不破前低）= 0xToni 的"回调守住前低"

## 执行步骤

### 快速判断（30秒版）
```
1. 打开日线图，找最近 6 个摆动高低点（左3右3）
2. 高点越来越高？低点越来越高？→ 结构多头
3. 20MA 向上？→ 确认
4. 周线结构也是多头？→ 共振，有效
5. MACD 面积没缩？→ 没力竭，可跟
→ 五条都满足才是"真·趋势确认"
```

### 脚本运行
```bash
# v3 增强版（推荐）
python3 ~/Downloads/_research/trend_structure_tracker_v3.py

# v2 原始版（仅参考，回测证明是反指）

```
- 数据源：tushare fund_daily（ETF）
- 输出全中文：上涨趋势/下跌趋势/扩散/收缩/中枢上方/中枢下方/共振/矛盾
- 五层过滤：日线结构 → 周线共振 → 背驰 → 中枢位置 → 三买
- JSON 输出：`~/Downloads/_research/trend_signal_v3.json`

### 集成到虾复盘/选股
- 虾复盘日度：在"市场状态"判断前，先跑三标的结构信号作为参考
- 选股引擎：T0 复盘的 `execution_regime` 可参考结构信号
  - 结构 uptrend + 20MA↑ + 周线共振 → `chase_allowed`
  - 结构 uptrend + 20MA↓ → `dip_only`
  - 结构 downtrend → `wait`

## 参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| L (左窗口) | 3 | 摆动点左侧确认 K 线数 |
| R (右窗口) | 3 | 摆动点右侧确认 K 线数 |
| lookback | 6 | 结构判断用最近 N 个摆动点 |
| ma_fast | 5 | 短期均线（情绪） |
| ma_slow | 20 | 中期均线（成本） |
| hold_days | 20 | 回测持有期 |

## Pitfalls

1. **A 股 ETF 纯趋势跟踪是反指** — 必须叠加周线级别 + 背驰
2. **摆动点有滞后** — 右窗口 R=3 意味着信号延迟 3 根 K 线
3. **通信ETF 等有小盘 ETF 流动性差** — 结构信号可能被单笔大单扭曲
4. **除权除息** — tushare qfq 数据已复权，但摆动点跨除权日可能失真
5. **0xToni 内容标注 "Made with AI"** — 理论深度有限，不要当作交易圣经
