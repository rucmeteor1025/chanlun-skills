# 板块均线位置表（WuChuan Style）

## 原理

源自吴川（微博/ X 股票博主）的板块强弱跟踪方法。核心逻辑：

> **一个板块收盘价站上多少条均线（5/10/20/30/60/120/250日），决定了它的多周期趋势强度。**

站上越多 → 多周期趋势共振越强 → 板块越强势。反之亦然。

## 脚本位置

```
~/.hermes/scripts/ma_table.py
```

依赖：Wind MCP（`wind-mcp-skill`），需先配置 `WIND_API_KEY`。

## 用法

```bash
# 全部 30 个板块（宽基+行业）
python3 ~/.hermes/scripts/ma_table.py

# 按分组查看
python3 ~/.hermes/scripts/ma_table.py tech     # 科技线：半导体/机器人/AI/算力/信息技术/科创50
python3 ~/.hermes/scripts/ma_table.py theme    # 题材线：新能源/光伏/低空经济/创新药/军工
python3 ~/.hermes/scripts/ma_table.py broad    # 宽基：上证/沪深300/创业板/科创50
python3 ~/.hermes/scripts/ma_table.py trad     # 传统行业：银行/券商/煤炭/消费/地产等
python3 ~/.hermes/scripts/ma_table.py health   # 医药线：医疗保健II/创新药
```

## 输出解读

```
板块           最新价    涨跌    5日   10日   20日   30日   60日  120日  250日   站上
──────────────────────────────────────────────────────────────────────────────
机器人          9870 +3.58%    ✅     ✅     ✅     ✅     ✅     ✅     ✅   7/7
半导体         12822 -1.73%    ❌     ❌     ✅     ✅     ✅     ✅     ✅   5/7
上证指数        4044 +0.37%    ❌     ❌     ❌     ❌     ❌     ❌     ✅   1/7
```

| 列 | 含义 |
|---|---|
| 板块 | 板块/指数名称 |
| 最新价 | 当日收盘点位 |
| 涨跌 | 当日涨跌幅 |
| 5日 ~ 250日 | ✅=收盘价站上该均线，❌=跌破，·=数据不足 |
| 站上 | 站上数/总有效均线数（满分7/7） |

### 趋势强度分组

| 站上数 | 趋势状态 | 含义 |
|---|---|---|
| **≥5/7** | 🔥 强势 | 中长期趋势完好，主升或回调可做多 |
| **3-4/7** | 👀 中性 | 趋势模糊，震荡市，等方向 |
| **≤2/7** | ⚠️ 弱势 | 空头排列，回避或等底部信号 |

### 关键用法

1. **相对强弱对比** — 不看单个板块的绝对值，看板块之间的站上数排名。当前钱在哪些板块、不在哪些板块，一目了然。
2. **站上数变化趋势** — 同一个板块的站上数从低到高变化（如 2/7→4/7→6/7）= 趋势走强；从高到低 = 趋势走弱。
3. **均线排列形态** — 单看站上数不够，要看排列：
   - 多头排列（5>10>20>60>120>250）= 最强
   - 空头排列（5<10<20<60<120<250）= 最弱
   - 均线黏合 = 变盘前夜
4. **板块轮动判断** — 强势板块数量 vs 弱势板块数量比例变化，判断市场整体风格（进攻/防御/震荡）。

## 技术细节

### Wind MCP CLI 调用注意事项

Python 通过 subprocess 调用 Wind MCP CLI 时，JSON 参数必须被 shell 正确转义。已验证的可靠方式：

```python
import subprocess, shlex, json

params = json.dumps({...}, separators=(",", ":"))  # 无空格JSON
cmd = f"node scripts/cli.mjs call server_type tool {shlex.quote(params)}"
r = subprocess.run(cmd, capture_output=True, text=True, timeout=30,
                   cwd=SKILL_DIR, shell=True)
```

关键点：
- 必须 `shell=True` + `shlex.quote(params)` — 直接传列表形式会空输出
- JSON 用 `separators=(",", ":")` 去空格，避免 shell 解析歧义
- 必须设 `cwd=SKILL_DIR`，CLI 依赖相对路径找资源
- 返回的 stdout 是**多行 JSON**，需要手动找完整 JSON 边界再解析

### 均线计算

使用 numpy 简单移动平均：`np.mean(closes[-n:])`。Wind K 线数据的 `MATCH` 字段是当日收盘价。

### 数据周期

脚本请求约 550 个自然日的数据，保证 250 个交易日以上的 K 线覆盖。如果某板块 K 线不足 250 日，对应长周期均线显示 `·`。
