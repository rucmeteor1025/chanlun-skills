# EMA 指数移动平均线 — 快速参考

## 公式
```
EMA_t = P_t × α + EMA_(t-1) × (1-α),  α = 2 / (n+1)
SMA_t = (P_1 + P_2 + ... + P_n) / n
```

## 特点对比

| 维度 | EMA | SMA |
|---|---|---|
| 权重 | 近期指数衰减 | 所有等权重 |
| 反应速度 | 快 30-50% | 慢、平滑 |
| 趋势市 | 早进场早出场 | 滞后 1-3 天 |
| 震荡市 | 易假信号 | 更稳定 |

→ 不是"谁更好"，是互补：EMA 做趋势识别，SMA 做信号确认。

## A 股常用参数

| 用途 | EMA | SMA 对应 |
|---|---|---|
| 短线/超短线 | EMA5/8/10 | MA5 |
| MACD 源 | EMA12/26 | MA10/20 |
| 波段多空 | EMA20 | MA20 |
| 牛熊分界 | EMA60 | MA60 |
| 长期趋势 | EMA120/250 | MA120/250 |

## 实战组合

1. **EMA12 金叉 EMA26** → 趋势转多（MACD 源）
2. **EMA20 斜率** → 趋势强度
3. **EMA60 多空分界** → EMA20 在其上方只看多，下方只看空
4. **SMA 确认** → EMA 出信号后等 SMA 确认再动手

## 解读要点

- 价格在所有 EMA 之下（空头排列 EMA5<10<20<60）→ 趋势偏空
- 价格在所有 EMA 之上（多头排列 5>10>20>60）→ 趋势偏多
- 均线粘合（各周期接近）→ 趋势不明，等待突破
- EMA60 是中期牛熊转换的关键观察位
- 价格跌破 EMA60 后首次站回 → 可能的中期反转信号
- 支撑/阻力：EMA 聚合区（多线接近）提供更强的支撑/阻力
